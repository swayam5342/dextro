# Security

## Reporting a problem

Please report security problems privately, not in a public issue. Use **Report a vulnerability** on the [Security tab](https://github.com/swayam5342/tributary/security/advisories/new) of this repository.

Say what you found, how to reproduce it and which version you're running. `tributary-cli version` shows it.

This is a project with one maintainer, so there's no guaranteed response time, but reports are taken seriously and you'll be credited if you'd like to be.

## Supported versions

Only the latest release gets security fixes. Self-hosted servers need updating by whoever runs them.

## What's in scope

Problems in this repository: the server, the web app, the published Docker images and the website.

Google's own services, and a server someone has set up without HTTPS or with weak secrets, aren't in scope.
